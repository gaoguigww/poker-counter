# 扑克记牌器（手机版）

手机浏览器打开就能用的记牌器：只输入**对方打出的牌**，实时统计剩余牌数。

## 在线地址

https://gaoguigww.github.io/poker-counter/

## 用法

- 点一下某个点数：记 1 张
- 长按某个点数：该点数剩余的全部一次记下（对子、三张、顺子）
- 底部按钮切换「＋出牌 / －回退」，撤销、重开
- 右上角齿轮：换玩法（斗地主 54 / 掼蛋 108 / 德州 52）、触感开关、清空本局

记录存在浏览器本地，刷新、锁屏都不会丢；纯前端，不联网、不上传任何数据。

## 文件

index.html 单文件应用，零依赖，可直接双击在电脑上打开。
